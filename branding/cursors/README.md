# Cursors

[Bibata Modern](https://github.com/ful1e5/Bibata_Cursor) v2.0.7 by Abdulkaiz
Khatri, GPL-3.0 (`LICENSE`, installed as
`/usr/share/licenses/bibata-cursor-themes/LICENSE`). Fedora doesn't package
it, so the archives are kept here as downloaded from the v2.0.7 release.
`build_files/build.sh` checks their SHA-256 (below); a new version means new
archives and new sums in both places.

- `Bibata-Modern-Ice.tar.xz`: `a68cae60c4dc706350e194ebc91c5fe48bc7bc9d59e119555834a2a7ee5078ef`
- `Bibata-Modern-Classic.tar.xz`: `7d3495864e5bbef02f5e77de760b2905903b63c71495a78ef6306d19a3b556d8`

- `Bibata-Modern-Ice`: white, for AtlasOS Light (and the default everywhere
  else: the login screen, apps outside Plasma).
- `Bibata-Modern-Classic`: black, for AtlasOS Dark.

They replace Breeze's cursors, which the image no longer has.
