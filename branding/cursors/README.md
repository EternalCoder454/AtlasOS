# Cursors

[Bibata Modern](https://github.com/ful1e5/Bibata_Cursor) v2.0.6 by Abdulkaiz
Khatri, GPL-3.0 (`LICENSE`, installed as
`/usr/share/licenses/bibata-cursor-themes/LICENSE`). Fedora doesn't package
it, so the archives are kept here as downloaded.

- `Bibata-Modern-Ice`: white, for AtlasOS Light (and the default everywhere
  else: the login screen, apps outside Plasma).
- `Bibata-Modern-Classic`: black, for AtlasOS Dark.

They replace Breeze's cursors, which the image no longer has.
